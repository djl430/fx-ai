# 第一份作业原纸批改答案浮卡设计

## 目标

在第一份作业 `cluster-homework` 的按学生批改视图中，为原纸直批提供就近的标准答案参考，同时不恢复右侧结构化工具、不遮挡学生作答、不改变作业纸排版。

## 已确认方案

每道可点击题目内渲染一张精简答案卡。卡片默认隐藏；Hover 或键盘聚焦题目时，在题目左侧、作业纸外的空白区域出现，并与题目顶部对齐。

选择该方案是因为它让教师的视线只需在当前题目与左侧答案之间短距离移动。固定侧栏与滚动中的题目对应关系较弱；在题目内部展开答案会改变纸张高度并造成跳动。

## 答案内容

- 普通选择、填空题：显示“标准答案”和答案正文。
- 第 4 题增减性：补充“`x＜2` 时递减”“`x＞2` 时递增”两个评分点。
- 第 6 题综合判断：补充“开口向上”“对称轴 `x = 2`”“顶点（2，−1）”三个评分点。
- 不默认展示完整解析，避免浮卡过大。
- 答案卡使用中性的白底和蓝灰文字，不使用正确/错误状态色，避免与当前批改结果混淆。

## 交互

- Hover 题目：答案卡淡入并轻微向右移动到位。
- 键盘聚焦题目：展示同一答案卡。
- 点击或按 Enter/Space 切换批改结果：页面更新后，当前题目的答案卡继续显示 1.6 秒。
- 1.6 秒后若鼠标和焦点均已离开，答案卡自动隐藏。
- 答案卡不接收鼠标事件，整题点击切换结果的操作范围不变。

## 布局与响应式

- 桌面宽屏：卡片宽约 188px，位于题目左侧纸外空白区，箭头指向当前题目。
- 窄于 1400px：卡片回退到题目上方的小浮层，避免横向溢出。
- 卡片随所在作业页一起滚动，多页作业无需额外定位计算。

## 可访问性

- 题目通过 `aria-describedby` 关联对应答案卡。
- 答案卡使用 `role="note"`。
- Enter/Space 切换后恢复到更新后的同一道题，支持连续键盘批改。

## 范围

- 仅第一份作业的按学生批改启用。
- 保留当前题目 Hover 高亮、点击结果循环、学生列表和底部确认按钮。
- 按题批改、其他作业和考试不变。

## 验收标准

1. Hover 或聚焦任一题目时，左侧展示该题标准答案。
2. 第 4、6 题答案卡包含分点评分参考。
3. 答案卡不遮挡学生作答，也不拦截整题点击。
4. 点击修改结果后答案卡保持约 1.6 秒。
5. 键盘切换结果后焦点仍在同一道题。
6. 窄屏使用题目上方浮层，不产生新的横向滚动。
7. 其他任务不出现答案浮卡。
