# 第三份作业按学生结构化赋分设计

## 背景与问题

第三份任务 `quiz` 是“一次函数随堂检测”，入口为 `grading-by-question-demo.html?mode=exam&taskId=quiz`。当前批改页进入考试模式后仍复用第一份作业的二次函数题目，并且按学生模式对所有题目只提供统一的数字输入框，没有按题型生成赋分工具。因此页面缺少第三份作业专属内容，也不能完成“客观题判对错、主观题输入分数”的结构化赋分。

## 目标

- 为第三份任务提供覆盖选择题、判断题、填空题和解答题的专属试题数据。
- 每一页学生原卷右侧展示与该页题目一一对应的结构化赋分工具。
- 选择题、判断题由老师选择“对”或“错”，系统自动换算为满分或 0 分。
- 填空题、解答题由老师输入 0 到本题满分之间的分数，支持 0.5 分步进。
- 按学生赋分与按题赋分共用 `student.result` 和 `student.score`，两种视图实时同步。
- 考试模式下使用“赋分”文案，学生列表显示累计得分而不是正确率。

## 交互设计

### 页面结构

第三份任务包含 8 道演示题，每页 2 题，共 4 个上下连续的页面单元。每个单元左侧是模拟学生原卷，右侧是对应页的结构化赋分工具。页面和工具处于同一个滚动容器内，随整份试卷一起上下移动。

### 客观题

选择题和判断题的工具头部显示题号、题型、当前得分与满分。工具区提供带文字的“✓ 对”和“× 错”按钮：

- 选择“对”：`student.result = "correct"`，`student.score = maxScore(question)`。
- 选择“错”：`student.result = "wrong"`，`student.score = 0`。
- 当前选择以绿色或红色描边状态展示。

### 主观题

填空题和解答题显示数字输入框，范围为 0 到本题满分，步进 0.5 分：

- 满分同步为 `correct`。
- 0 分同步为 `wrong`。
- 介于 0 和满分之间同步为 `partial`。

### 同步与确认

所有赋分操作直接修改既有学生作答对象。切回按题赋分时沿用同一份得分与结果数据。单个学生和全班确认按钮在考试模式下分别显示“确认本学生赋分”和“一键确认赋分”；确认后保持现有自动进入下一位未确认学生的流程。

## 视觉原则

延续现有页面克制、工具型的浅色视觉。结构化工具保持紧凑纵向排布，通过题型标签、当前分值和明确的对错按钮建立信息层级，不引入新的浮层或侧栏。客观题状态沿用绿色正确、红色错误；主观题输入采用现有边框和圆角规范。

## 验收标准

1. 打开第三份任务并切换到按学生模式，不再出现空白或第一份作业题目。
2. 4 个页面单元均同时展示原卷与对应的结构化赋分工具。
3. 选择题、判断题只有对错操作；点击后得分自动变为满分或 0 分。
4. 填空题、解答题显示数字输入；修改分数后批改结果同步变化。
5. 学生列表显示累计分值，考试模式按钮与可访问标签使用“赋分”。
6. 原有第一份作业原纸批改、第二份作业结构化批改和按题模式不回归。
