# 第一份作业真实题面与行内批改标记设计

## 目标

让 `cluster-homework` 的按学生批改页面看起来像真实学生作业：题目内容与题型一致，学生答案出现在实际答题位置，批改符号紧贴答案，而不是悬浮在题目右上角。

## 范围

- 仅修改第一份作业的按学生批改题面。
- 保持整题 hover、点击循环“对 → 错 → 半对 → 对”、键盘操作和结果同步不变。
- 其他作业、考试及其结构化批改工具保持原样。

## 采用方案

为第一份作业的 6 道题提供专用题面模板，复用现有 `question` 和 `student` 数据：

1. 选择题：展示完整题干和 A–D 选项；将学生作答转换为选项字母并嵌入题干括号。
2. 填空题：题干后提供答题横线，学生原始答案写在横线上。
3. 解答题：展示明确问题和答题区，保留学生原始表达。
4. 综合题：展示三个待判断要点和一块综合答题区。

根据题型文字自动拼题干会产生语义不匹配；全面扩充所有题目的数据模型则超出本次范围，因此不采用。

## 题面内容

- 第 1 题：判断 `y = 2x² − 4x + 1` 的开口方向，提供 A.向下、B.向上、C.向左、D.向右。
- 第 2 题：求 `y = x² − 4x + 3` 的对称轴，填空作答。
- 第 3 题：求同一函数的顶点坐标，填空作答。
- 第 4 题：写出函数在对称轴两侧的增减性，解答区作答。
- 第 5 题：写出函数最小值，填空作答。
- 第 6 题：综合填写开口方向、对称轴和顶点，综合答题区作答。

## 批改标记

- 第一份作业的对、错、半对标记使用 `.student-paper-mark.is-inline`。
- 标记与答案放在同一个 `.student-paper-response` 或题干括号区域中。
- 标记尺寸略小于原悬浮批注，跟随答案自然排版。
- 考试分数标记和其他任务原有右上角标记不变。

## 底部操作按钮

- 按学生批改左侧“一键确认批改”和右侧“确认批改”统一采用按题批改的 `.button.primary` 样式。
- 移除学生视图单独覆盖的浅蓝渐变、纯蓝背景和胶囊圆角。
- 两个按钮使用与按题批改一致的 10px 圆角、38px 高度和深蓝渐变阴影；左侧按钮保持撑满侧栏，右侧按钮保持固定最小宽度。

## 验收标准

1. 第 1 题有完整题干、四个选项，学生作答字母显示在括号中。
2. 第 2–6 题都有与题型匹配的题干和答题位置。
3. 学生答案不再统一显示为“学生作答：……”的占位块。
4. 批改标记位于学生答案旁，且点击整题切换结果后立即更新。
5. 第一份作业以外的任务保持现有渲染。
6. 按学生批改底部两个按钮与按题批改按钮的颜色、圆角和高度一致。
