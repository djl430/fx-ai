# 按学生批改分页工具联动设计

## 目标

按学生批改时，每张学生作业页必须和该页的结构化批改工具保持一一对应，并在同一个纵向滚动区域内一起移动。单个学生的“确认批改”属于整份作业操作，不得放在任一页的工具栏中。

## 方案选择

采用“共享滚动容器中的分页行”方案。每个分页行由左侧作业页和右侧该页工具组成，所有分页行纵向排列。该方案直接通过 DOM 结构保证同步，不依赖双滚动容器监听或滚动位置换算。

未采用的方案：

- 固定右侧工具、根据当前作业页动态换页：切页时工具内容会跳变，不符合“跟随作业上下滑动”的直观预期。
- 作业区和工具区各自滚动并用脚本同步：容易出现高度差和累计误差，也增加维护复杂度。

## 页面结构

- 左侧学生名单保持独立，底部保留“一键确认批改”。
- 右侧评阅区域分为两行：分页内容滚动区、整份作业固定底栏。
- 分页内容滚动区包含多个 `.student-page-row`。
- 每个分页行包含一张 `.student-paper` 和一个 `.student-tool-panel`。
- 工具面板页码显示当前页/总页数，例如 `1/2`、`2/2`。
- 整份作业底栏横跨作业页与工具区，右侧放置单个学生“确认批改”按钮。

## 分页规则

- 普通作业每页展示 3 道题，当前 6 道题形成 2 页。
- 考试每页展示 2 道题，使长试卷能体现多页结构。
- 每页工具只渲染该页题目，题号和批改结果继续使用原始题目数据。

## 交互与状态

- 在共享滚动区上下滚动时，作业页与对应工具自然同步移动。
- 正确、错误、全对、全错、逐空和考试赋分操作保持不变。
- 修改批改结果时保留当前滚动位置。
- 切换学生后回到该学生第一页。
- 点击底栏“确认批改”后沿用现有逻辑，确认当前学生并自动进入下一位未确认学生。

## 验收标准

- DOM 中存在共享分页滚动容器和分页行。
- 每个分页行同时包含作业页与工具面板。
- 当前普通作业渲染至少两页，并显示正确页码。
- 工具面板内部不再拥有独立纵向滚动条和确认按钮。
- 单个学生确认按钮位于评阅区域整体底栏。
- 左侧一键确认、结果同步和按题批改均不受影响。
