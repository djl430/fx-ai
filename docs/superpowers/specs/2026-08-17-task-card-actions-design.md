# 列表页任务卡操作入口设计

## 目标

在首页每份作业或考试任务卡中增加“批改、学情、讲评”三个独立操作，让教师无需先打开任务详情即可进入常用工作流。

## 交互与布局

- 三个操作位于任务标题信息和右侧状态信息之间，保持卡片单行结构。
- “批改”使用品牌色实心样式，作为主操作；“学情、讲评”使用浅色次级样式。
- 每个按钮都有独立的 `data-action`，点击按钮不会触发卡片的其他行为。
- 处理中任务点击“批改”时继续显示现有分析中提示，不允许提前进入批改。
- 窄屏下任务卡允许换行，操作区保持三个按钮成组展示。

## 路由

- “批改”复用已有 `open-task` 路由，根据任务类型进入 `grading-by-question-demo.html`，并保留动态任务的标题、类型、班级、人数、页数参数。
- “学情”与“讲评”在当前演示范围内提供可点击反馈，通过页面提示说明所选任务与目标功能；不虚构尚不存在的详情页。

## 验收

- 每个任务卡渲染三种操作。
- “批改”按钮具有任务 ID，点击后进入对应批改页。
- “学情、讲评”按钮可点击并显示任务级提示。
- 既有任务筛选、分析进度、批改入口与全量测试保持可用。
