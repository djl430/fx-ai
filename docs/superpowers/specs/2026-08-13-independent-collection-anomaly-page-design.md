# 独立采集异常处理页设计

## 目标

将提交异常处理从 `collection-confirm.html` 的页内阶段拆出，形成独立的 `collection-anomalies.html`。样卷确认页只负责样卷分组、类型、名称和页面归属；异常页只负责逐份样卷查看缺页及处理未识别单页。

## 页面流程

1. 老师在样卷确认页完成样卷调整。
2. 若没有提交异常，点击确认后直接创建作业并返回列表页。
3. 若存在缺页或未识别页面，点击确认后保存当前样卷草稿并跳转到 `collection-anomalies.html?task=<taskId>`。
4. 异常页从草稿中读取样卷与异常数据。顶部横向切换样卷，左侧仅展示当前样卷的异常项，中间预览原作业页面，右侧仅在未识别页面时展示学生归属操作。
5. 未识别页面全部归属后，老师点击开始分析，系统创建作业并返回列表页。
6. 缺页只提示重新扫描，不阻塞开始分析。
7. 老师可点击“返回修改样卷”回到确认页，已调整的样卷和已完成的页面归属均保留。

## 状态与导航

- 样卷确认页把当前 `groups`、`anomalies`、任务信息和来源任务 ID 写入 `localStorage` 中的独立采集草稿键。
- 异常页通过任务 ID 校验并读取草稿，所有归属操作即时回写草稿，因此刷新页面不会丢失进度。
- 返回确认页时带 `resumeCollection=1`，确认页优先恢复草稿，不重新生成演示数据。
- 完成分析后沿用现有批次、历史记录和五秒分析流程；清除当前采集草稿，跳转 `index.html?collectionCreated=1`。
- 只允许未解决的“未识别学生”异常阻塞开始分析，缺页始终计入异常数量但不阻塞。

## 异常页交互

### 样卷导航

- 样卷切换固定在工作区顶部横向展示。
- 每个样卷显示名称、异常总数和待归属页面数。
- 左侧不重复展示样卷列表，只显示当前样卷的缺页学生和未识别页面。

### 缺页

- 中间预览区展示学生已有页面及缺失页码。
- 缺失页码后直接显示“请重新扫描缺失页面”。
- 不展示右侧操作栏，不要求老师确认，不阻塞开始分析。

### 未识别页面

- 每条异常代表一张未识别纸张，而不是整份作业。
- 中间区域直接预览该单张纸。
- 右侧默认展示优先推荐学生；“全部学生”默认收起，输入搜索词时自动展开。
- 选择学生并点击“确认归属”后：
  - 将该页归入所选学生在当前样卷中的作业；
  - 页面中上方 Toast 提示“已归属给 <学生名>”；
  - 左侧该“未识别页面”下方立即由“未识别学生”更新为学生名，并显示已处理状态；
  - 自动定位到当前样卷的下一张未归属页面；若当前样卷已处理完，则定位下一份仍有未归属页面的样卷。

## 页面职责

- `collection-confirm.html`：编辑样卷、保存草稿、决定直接完成或跳转异常页，不再渲染异常处理工作区。
- `collection-anomalies.html`：读取草稿、渲染异常处理界面、保存归属、完成批次创建。
- `collection-flow.js`：继续提供异常分组、阻塞异常筛选、归属更新、批次与历史状态转换，避免页面间复制业务规则。

## 异常与兜底

- 草稿不存在或任务 ID 不匹配时，异常页展示说明并提供返回采集记录入口，不创建空作业。
- 已解决异常可以查看但不重复阻塞；重新选择学生时覆盖归属并即时保存。
- 页面刷新按草稿恢复当前处理状态，默认定位到第一张未归属页面；若已全部归属，则定位第一条异常供查看。

## 验收标准

- 样卷确认页不再包含异常处理页内阶段或弹层。
- 有异常时确认样卷会跳转独立 URL；无异常时仍直接创建作业。
- 缺页无右栏且不阻塞；未识别页面可搜索、选择并确认学生。
- 确认归属后出现中上方 Toast，左侧学生名立即更新并自动前进。
- 刷新异常页、返回修改样卷再进入异常页，归属状态保持。
- 完成后仍生成对应作业/考试，进入五秒 AI 分析流程并停留列表页。
