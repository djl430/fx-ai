# 按题/按学生双模式批改设计

## 目标

在 `grading-by-question-demo.html` 中将“预览学生留痕”入口替换为“按题批改 / 按学生批改”切换控件。默认进入按题批改；新增按学生批改三栏工作区，并让两种模式共享同一份学生题目结果数据。

同时修正按题批改右侧结果导航：只保留与正确、半对、错误、未批改对应的四条横线，移除重复装饰刻度。

## 模式切换

- 顶部右侧使用分段按钮呈现“按题批改”和“按学生批改”。
- 首次打开默认选择按题批改，不增加新的 URL 参数。
- 切换仅改变工作区展示，不重新加载页面，也不重建题目或学生状态。
- 切回按题批改时保留当前题；切回按学生批改时保留当前学生。
- 现有返回列表、确认题目、确认全部题目、作业与考试模式逻辑保持可用。

## 按题批改

- 保留现有题号导航、答案与 AI 批改依据、四类学生作答分组和确认操作。
- 结果快捷导航仍固定在内容区右侧，但容器透明且没有重复刻度背景。
- 导航只显示四个可点击横线；当前结果加深并加长，点击和滚动同步逻辑保持不变。

## 按学生批改布局

采用与参考图一致的三栏结构：

1. 左侧学生列表：显示学生姓名、完成状态与当前正确率；当前学生高亮。点击后更新中间作业纸和右侧工具。
2. 中间作业区：复用 `student-trace-preview.html` 的纸张视觉语言，在页面中央呈现当前学生姓名、题目、答案和批改符号。作业区可独立滚动。
3. 右侧结构化批改工具：按题列出题号、学生答案和批改控件，工具区可独立滚动；底部提供“确认本学生批改”。

页面不依赖新的扫描图片资源，使用现有题目、答案和纸张样式生成可交互演示内容。

## 结果交互与数据同步

- 现有数据由“每道题下的学生作答结果”组织；按学生模式通过学生 ID 聚合所有题目，无需复制状态。
- 作业模式下，每题提供正确、半对、错误、未批改四个互斥选项。
- 点击选项直接修改该题中对应学生的 `result`，同时更新右侧选中态与中间纸张批改符号。
- 切回按题模式后，该学生自动出现在对应结果分组，统计人数随之更新。
- 考试模式下沿用现有 0.5 分步进的得分输入，并根据得分同步正确、半对或错误结果。
- “确认本学生批改”将当前学生涉及的题目视为已检查，并自动切换到下一名学生；不改变现有按题确认和全部确认的持久化规则。

## 状态与边界

- 当前演示数据中的姓名唯一，因此按学生模式使用姓名作为跨题稳定键；每道题内部仍保留现有学生 ID 用于精确修改。
- 某题缺少当前学生时，右侧显示“暂无作答”，不创建虚假答案。
- 未批改结果在作业纸上不显示对错符号；半对、正确、错误使用仓库内现有符号资源。
- 每次切换学生或修改结果后，只更新按学生工作区；切换回按题模式时通过现有 `renderAll()` 重新生成分组。
- 窄屏下三栏保持最小宽度并允许页面横向滚动，不压缩作业纸到不可读尺寸。

## 验证

- 测试确认“预览学生留痕”入口已移除，双模式切换控件存在且按题模式默认激活。
- 测试确认按学生工作区包含学生列表、居中作业纸、结构化题目工具和确认按钮。
- 测试确认四态操作修改共享的学生结果对象，考试模式继续提交得分。
- 测试确认结果导航只有四个按钮且没有重复刻度背景。
- 浏览器检查模式切换、学生切换、结果双向同步、独立滚动区域和不同宽度下的布局。
