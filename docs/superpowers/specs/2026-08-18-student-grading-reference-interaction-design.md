# 按学生批改参考图交互设计

## 目标

将按学生批改工作区调整为参考图中的三栏交互：左侧学生列表与批量确认，中间居中的学生原卷，右侧逐题结构化批改工具。所有判定继续直接修改共享的学生答题数据，确保切回按题批改时结果一致。

## 左侧学生列表

- 顶部保留“学生列表”和已确认人数。
- 中部名单保持可滚动，展示姓名、确认状态和正确率。
- 底部固定“一键确认批改”主按钮。
- 点击后将全部学生标为已确认，同时复用题目完成持久化逻辑，将任务状态同步为批改完成。

## 中间原卷

- 保持学生作业在工作区居中、独立滚动。
- 题目判定变化后，原卷上的勾、叉或分数即时更新。
- 原卷与右侧工具共享当前学生和答题数据，不复制状态。

## 右侧批改工具

- 顶部只展示页码 `1/1`，贴近参考图的信息层级。
- 普通题显示题号、正确勾、错误叉、更多入口以及答案。
- 复合题显示“全对 / 全错”快捷操作，并列出 `空1、空2…` 的独立勾叉判定。
- 子项混合判定时整题自动同步为“半对”；全部正确或全部错误时同步为对应整题状态。
- 底部固定“确认批改”，确认当前学生后自动进入下一位未确认学生。

## 验收

- 学生列表底部存在并可操作“一键确认批改”。
- 右侧存在页码、逐题勾叉、复合题全对/全错和分空批改。
- 当前学生确认和全部学生确认均更新确认状态。
- 按学生修改后，按题批改读取到相同的 `student.result`。
- 全量页面与数据流测试保持通过。
