# 考试赋分直接输入设计

## 目标

在按题批改页面的考试模式中，教师可以直接修改每位学生当前题目的得分，不再依赖点击答题卡循环调整分数。

## 范围

- 仅作用于 `mode=exam` 的赋分页面。
- 每张学生答题卡右上角展示一个紧凑的数字输入框，右侧保留“/ 满分 分”。
- 作业模式维持原有批改交互，不新增输入框。

## 交互规则

1. 输入框初始值为当前学生得分。
2. 允许范围为 0 至当前题满分，步长为 0.5 分。
3. 教师按 Enter 或输入框失焦时提交修改：数值会被限制在合法范围并对齐到 0.5 分。
4. 分数修改后立即更新答题卡、分组统计和左侧题目得分指标。
5. 考试模式点击答题卡本身不再改变分数，避免与输入操作冲突。
6. 题目确认逻辑和任务完成状态沿用现有逻辑。

## 数据与验证

- 分数保存在当前学生对象的 `score` 字段，沿用现有数据模型。
- 无法解析的输入恢复到修改前的有效分数。
- 通过页面回归测试检查考试模式的输入控件、边界约束和作业模式隔离。
