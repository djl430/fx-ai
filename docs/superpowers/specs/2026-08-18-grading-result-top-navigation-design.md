# 按题批改结果顶部定位导航设计

## 目标

将按题批改结果区右侧的四条短横线导航，替换为结果区顶部的横向文字定位导航，让教师可直接识别并跳转到“正确、半对、错误、未批改”四个分组。

## 交互

- 导航位于按题批改内容区顶部工具栏左侧，密度选择器仍位于右侧。
- 四个入口按页面分组顺序排列：正确、半对、错误、未批改。
- 点击入口后，仅平滑滚动批改结果容器，将目标分组定位到容器顶部附近。
- 手动滚动结果容器时，导航同步高亮当前分组；滚动到底部时高亮最后一个分组。
- 当前入口使用对应结果色和下划线强调，并通过 `aria-current` 暴露当前状态。
- 空分组继续保留并可定位；形似作答模式定位到同结果的第一个分组。

## 页面调整

- 移除 `.result-rail` 右侧短横线导航及其响应式预留空间。
- 将 `.groups-scroll` 右侧内边距恢复为与左侧一致，释放作答卡片空间。
- 复用现有滚动定位和滚动同步逻辑，只将控制器命名调整为顶部导航语义。
- 按学生批改页面、题目列表、作答数据和批改状态逻辑保持不变。

## 验证

- 静态测试确认顶部导航含四个结果入口，右侧短横线结构和样式已移除。
- 交互契约测试确认点击使用平滑滚动，手动滚动同步激活状态，并保留可访问状态。
- 完整测试套件和内联脚本语法检查必须通过。
