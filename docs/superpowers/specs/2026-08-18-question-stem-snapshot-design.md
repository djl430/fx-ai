# 按题批改题干截图设计

## 目标

在按题批改的答案上方展示当前题目的题干截图缩略图，帮助教师在查看答案和批改依据前快速确认题目上下文；点击缩略图可放大查看完整截图。

## 方案

- 在辅助信息栏的答案卡上方增加独立“题干截图”卡片。
- 缩略图使用 `<img>` 展示，由当前题目数据动态生成 SVG 图片数据地址，确保它具有图片语义且切题后同步更新。
- 第一份作业的六道题提供对应的真实题干文案；其他任务使用“题号 + 题目名称 + 题型”生成可用的兜底截图。
- 图片保持试卷裁切质感：暖白纸张、横向书写线、题号、题型和正文，不在截图中暴露答案。

## 交互

- 缩略图按钮支持鼠标点击和键盘操作，并提供“放大查看第 N 题题干截图”的可访问名称。
- 点击后打开独立大图预览弹窗，标题随当前题目更新，展示与缩略图相同的高清图片。
- 关闭按钮、点击遮罩和 Esc 均可关闭；复用页面现有弹窗控制逻辑。
- 切换题目时同步更新缩略图、大图和标题。

## 边界

- 只在按题批改辅助栏展示；按学生批改页面不增加该卡片。
- 图片生成不依赖网络或外部文件，`file://` 直接打开也可使用。
- 不改动答案、解析、批改依据和批改结果状态。

## 验证

- 静态测试覆盖缩略图卡片、图片生成函数、动态更新、预览弹窗和关闭方式。
- 完整测试套件、内联脚本语法检查和差异检查必须通过。
